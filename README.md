# CarKey Lab

تطبيق تعليمي عربي محلي لتعلم مبادئ برمجة ريموتات السيارات عبر محتوى آمن ومحاكاة وتمارين.

## التشغيل

```bash
cd /home/ubuntu/car-key-lab
python3 -m http.server 4173 --bind 0.0.0.0
```

ثم افتح `http://localhost:4173` أو رابط المعاينة العام المقدم.

> المحاكي تعليمي ولا يتصل بأي مركبة أو جهاز فعلي. لا تستخدم المحتوى لتنفيذ إجراءات على مركبة دون تفويض قانوني ودليل المصنع.
